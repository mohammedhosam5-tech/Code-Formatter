# Code Formatter & Readability Tool

A browser-based tool for formatting formulas and code snippets,
improving readability, and exploring conditional logic.

Useful for nested IF expressions, Excel-style formulas,
business rules, and implementation scripts.

## Features

- Format formulas and code snippets with structured indentation.
- Highlight conditions, fields, values, operators, and brackets.
- Explore supported nested IF expressions through an interactive tree.
- Edit conditions and results directly in the visual tree.
- Review and apply pending edits.
- Undo the last tree edit.
- Review basic structural checks and complexity indicators.
- Copy formatted output or download it as a text file.
- Export the decision tree as an HTML document.

## Example Use Cases

- Make lengthy formulas easier to read.
- Review nested IF logic in Excel-style expressions.
- Understand calculations and business rules.
- Identify mismatched brackets or quotation marks.
- Share a visual explanation of conditional logic.

## Getting Started

1. Select Code → Download ZIP.
2. Extract the downloaded ZIP file.
3. Open index.html in your browser.
4. Paste a formula or code snippet.
5. Click Format Code.
6. Review the output, visual tree, and validation results.

No installation, server, or external API is required.

## Workspaces

### Formatter

View the original input alongside the formatted output,
with optional highlighting and keyword capitalization.

### Visual Tree Editor

Explore supported nested IF expressions, expand or collapse
branches, and edit conditions or return values.

### Review & Validation

Review detected fields, complexity indicators,
and basic structural warnings.

## Privacy

Processing happens locally in your browser.
The application does not upload pasted content to a server.

## Scope and Limitations

This tool assists with formatting and reviewing expressions.
It does not execute code or calculate formula results.

Support varies by syntax. Excel-style expressions are a use case;
complete Excel formula compatibility is not guaranteed.

The visual tree is designed for supported nested IF expressions.
Other conditional structures may not generate a tree.

Structural checks do not replace testing in the original
spreadsheet, application, or programming environment.

Review the formatted output before using it.
